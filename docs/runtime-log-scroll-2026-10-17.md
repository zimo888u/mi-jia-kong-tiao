# 2026-10-17 运行日志滚动修复

设置页原来的日志框是固定 168px 高度的裁剪矩形，内部只有 Text，没有滚动区域。日志超过可见高度后，后面的内容无法查看。

现在使用独立的纵向 ScrollView：内容高度跟随换行后的文本高度，溢出时显示滚动条，支持鼠标滚轮、拖动滑块和滚动条按钮。为滚动条预留文字空间，禁止横向滚动；清空或缩短日志时，限制原滚动位置，避免内容消失或留下空白。
