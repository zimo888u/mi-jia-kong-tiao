# 米家空调 v2.3.0

本版新增五种主题与开机自启动，修复最小化恢复闪屏和运行日志无法滚动，并改进设备切换、登录和凭据保存。

## 主要更新

- 修复最小化后恢复窗口时闪屏及最大化状态丢失，恢复时保留原窗口并完整重绘。
- 运行日志加入独立滚动区域，支持鼠标滚轮和拖动滚动条查看最近 200 条日志；清空或缩短日志后不会停在空白区域。
- 新增 macOS、丛雨·亮色和丛雨·暗色主题，与原有浅色、深色组成五种主题。丛雨主题副标题更新为 `Ciallo～(∠・ω< )⌒★`。
- 主题图片适配 Windows DPI 缩放，减少锯齿；生成显示纹理后释放完整解码源图，减少约 14.56 MiB 的常驻像素内存。
- 新增独立的软件主题页面和默认关闭的开机自启动。
- 改进设备切换和登录取消流程，避免沿用旧设备连接或旧账号的温湿度计；修复二维码居中、设备筛选和登录过期提示。
- 账号、空调和温湿度计凭据统一保存在单个 DPAPI 加密事务文件中，保存失败时保留旧状态。
- 收紧登录、网络响应和本地清理范围；一键清理仅进入本软件专属数据目录。

完整更新记录见 [CHANGELOG](https://github.com/zimo888u/mi-jia-kong-tiao/blob/v2.3.0/CHANGELOG.md)。

## 下载与使用

- `miac-app-v2.3.0-windows-x86_64.zip`：Windows x86-64 桌面便携版，解压后运行 `miac-app.exe` 或 `启动空调.cmd`。
- `miac-app.exe`：与便携包内相同的独立桌面程序。
- `miac-control-skill-v2.3.0-windows-x64.zip`：可选的 Codex 对话控制 Skill，包含同版桌面登录程序和助手。通用文件名 `miac-control-skill-windows-x64.zip` 的内容相同。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。

首次使用时，用米家 App 扫码并选择空调。已登录用户通常可以继续使用当前用户的数据；如需重新登录，按界面提示操作。

## 升级与兼容

- 凭据格式有更新，请同步升级桌面端、CLI 和 Skill 助手，避免混用旧版程序。Skill 安装方法见包内 `references/setup.md`。
- 保留 46 个型号的内置公开 MIoT 规格。规格与界面已做离线验证，不代表每款空调都已进行真机测试；控制能力取决于设备型号、固件和账号授权。
- 本版提供 Windows x86-64 程序。DPAPI 保护属于当前 Windows 用户范围，不能阻止以同一用户身份运行的程序解密。

## 验证

本版构建通过 212 项工作区测试、178 张界面截图检查、五种主题各 200 条日志的滚动检查、三轮共 21 项 Windows 原生重绘检查，以及 30 次最小化恢复检查。真机验证范围为此前已记录的局域网和云端只读状态查询，没有执行真实设备写操作或清理用户数据。
