# 米家空调 v2.3.1

> 此发行版已撤回公开列表，其自定义许可已在 [v2.3.2](v2.3.2.md) 中改为公开的 AFPL；请使用新版。下文只保留该次整理工作的记录。

本版整理项目授权和历史文件，移除未使用的早期代码，保留 v2.3.0 的主题、窗口恢复和日志滚动功能。

## 授权

- 当时使用的自定义许可已停止作为当前项目条款，新版改用公开发布的 AFPL；原有授权不被追溯更改。
- 普通用户原样运行程序控制自己的空调，无须公开个人配置或设备凭据。
- 第三方依赖和角色素材保留原权利，分发包随附完整的项目许可证与第三方声明。此许可为源码可用许可，不属于 OSI 定义的开源许可；此前已合法取得的旧版本许可不被追溯撤回。

## 清理

- 移除旧原型假数据模块、独立握手探测和临时读取示例；保留现行控制核心、CLI 和回归验证。
- 撤下过时的备份说明、旧截图、实施计划、未引用图片和包含本机信息的验收记录。源码中只保留项目文档和公开验证方法。
- 许可证与分发说明同步进入桌面便携包及可选的 Codex Skill 包。

## 下载

- `miac-app-v2.3.1-windows-x86_64.zip`：Windows x86-64 便携版，解压后运行 `miac-app.exe` 或 `启动空调.cmd`，请保留包内许可和声明文件。
- `miac-control-skill-v2.3.1-windows-x64.zip`：可选的对话控制 Skill。通用文件名 `miac-control-skill-windows-x64.zip` 的内容相同。
- `LICENSE`、`THIRD-PARTY-NOTICES.md` 与 `SHA256SUMS.txt`：许可、第三方声明与发行文件校验值。
