# 米家空调 v2.2.0

v2.2.0 扩展多型号支持，并改进运行日志、诊断展示和凭据保护。该发行版提供 Windows x86-64 桌面程序，以及可选的 Codex 对话控制 Skill。

## 本版更新

- 内置 46 个小米、智米和云米空调的公开 MIoT 规格；未知型号可尝试在线获取并缓存。
- 按设备真实型号决定可用的模式、风速、温度范围、步长和扩展控制，不按匹数猜测协议。
- 设置页可以导出本次运行的最近 200 条日志；诊断读数显示单位，自动刷新控件使用刷新图标。
- 登录、命令行和旧凭据升级统一采用当前 Windows 用户范围的 DPAPI 加密，自动连接方式保持不变。
- 可选安装 `miac-control-skill-windows-x64.zip`，通过 Codex 查询状态、室温和型号能力，并执行受型号规格校验的控制。

## 下载与首次使用

下载 `miac-app-v2.2.0-windows-x86_64.zip` 并解压，运行其中的 `miac-app.exe`。首次使用时选择扫码登录，用米家 App 扫码并选择空调设备。

Skill 是可选项。下载 `miac-control-skill-windows-x64.zip` 并按包内 `references/setup.md` 安装；首次登录仍通过桌面程序完成。

## 安全与兼容说明

- 可读取旧版 Electron 凭据；可读凭据会在新版启动时升级为 DPAPI 格式。旧版程序不能读取新版密文。
- 旧位置的明文凭据副本不会自动删除，设置页会提示检查。用户级 DPAPI 可抵御其他 Windows 用户直接读取凭据文件，但无法阻止同一用户权限下的程序解密。
- 内置规格通过离线解析与校验，新增型号尚未逐一进行真机验证。多个公开规格版本定义冲突时，程序会禁用未确认的模式写入。
- 发行版仅提供 Windows x86-64。
