# 米家空调 v2.1.0

v2.1.0 聚焦于 Windows 桌面端的常驻使用体验：应用现在只允许运行一个实例，重复启动会将已运行的窗口带回前台；关闭窗口时可以选择收进托盘或退出，并可保存偏好。

## 本版更新

- 增加单实例唤醒，避免重复打开多个控制窗口。
- 增加关闭确认弹窗和软件设置中的关闭行为选项。
- 设置改为后台串行写入，减少点击设置时的界面阻塞风险。
- 修复窗口最小化或从托盘恢复后软件渲染表面可能未正确刷新的问题。
- 新增应用图标资源，EXE、窗口与系统托盘使用同一套多尺寸图标。
- 优化温度调节、自动刷新和消息提示的界面更新路径。

## 下载

下载 `miac-app.exe` 后直接运行即可。首次使用时选择“扫码登录米家账号”，在米家 App 中扫码授权并选取空调设备。

## 已知说明

- 当前发行版仅提供 Windows x86-64 便携版。
- 局域网连接优先；若局域网不可用，可在软件设置中切换云端 RPC。
