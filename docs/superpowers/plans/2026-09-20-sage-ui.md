# Sage desktop UI implementation plan

**Goal:** Implement the approved five-page Figma design in the existing native Slint application.
**Architecture:** Keep the Rust/Slint property and callback contract and lazy page construction. Centralize sage light/dark colors and reusable card/button treatments, then rearrange existing live controls into spacious two-column layouts. Retain all controls omitted from the visual mockup.
**Tech stack:** Rust, Slint software renderer; no web runtime or image-heavy effects.

- [x] Theme and shell: update `ui/theme.slint`, `ui/common.slint`, and `ui/main.slint` with sage surfaces, pill navigation, generous spacing, page headlines and existing refresh/theme actions.
- [x] Control: rebuild `ui/pages/control.slint` with a large live dial, mode selector, airflow and preset column, environment/comfort/energy column; preserve every callback and 0.5°C adjustment bounds.
- [x] Remaining pages: lay out power statistics/calendar, diagnostic readings, raw-property tools and settings in `ui/pages/{power,diag,debug,settings}.slint`; use existing data exclusively.
- [x] Default: add a failing test for light-theme defaults, then change `Settings::default` while preserving saved preferences.
- [x] Validate with `cargo test --workspace`, `cargo build -p miac-app`, and rendered light/dark UI inspection. Record any platform-specific limitations. Inspect diff and provide code location and launch command.

Validation: native app builds on macOS; core tests, ten themed page renders, three compact renders and pointer/keyboard smoke checks pass. Windows hardware/tray/memory validation remains a target-machine check.
